# Hoomi mascot slot

The final Hoomi mascot (a gender-neutral robotic cat based on the Pixel Creative Strategist) is **not included** and has not been invented.

To use the real artwork, add one file here named `hoomi.png`, `hoomi.svg`, `hoomi.webp` or `hoomi.jpg`. The Welcome screen and the Hoomi page
pick it up automatically. Until then a labelled placeholder is shown. Only add artwork you have the right to use.
